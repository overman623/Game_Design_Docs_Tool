항목 순서

화살표를 눌러 먼저 보여줄 내용을 정하세요.

    01 게임 소개 이름, 한 줄 소개, 핵심 컨셉부터 적어 보세요.
    02 게임의 특징 차별점과 플레이어가 느낄 경험을 정리해 보세요.
    03 게임 플레이 방식 흐름, 시스템, 승패, 성장 구조를 적어 주세요.
    04 게임 이미지 메인·플레이·UI 이미지와 아트 컨셉을 넣어 주세요.
    이미지 없음
    메인 화면

    타이틀·로비처럼 첫인상을 보여주는 화면을 넣어 주세요.

    JPG, PNG, WEBP / 8MB 이하 권장

    이미지 없음
    플레이 화면

    실제 플레이가 보이는 핵심 인게임 장면을 넣어 주세요.

    JPG, PNG, WEBP / 8MB 이하 권장

    이미지 없음
    UI

    HUD, 메뉴, 인벤토리 등 UI 구성을 보여주는 이미지를 넣어 주세요.

    JPG, PNG, WEBP / 8MB 이하 권장

    05 시장 진출 계획 플랫폼, 유저, 출시 이후 계획을 정리해 보세요.
    06 팀 소개 및 역할 팀 이름과 인원·역할을 적어 주세요.
    07 개발 과정 에피소드 계기, 시행착오, 리디자인, 앞으로의 목표를 적어 주세요.

    게임 컨셉 기획서 사용 설명서

    1

    문서 모양을 먼저 정하세요

    00번에서 필요한 항목만 켜고 끌 수 있어요. 여백, 구분선, 제목 정렬, 항목 순서도 직접 바꿀 수 있습니다.

    2

    상위 항목을 따라 작성하세요

    게임 소개 → 특징 → 플레이 → 이미지 → 시장 → 팀 → 에피소드 순으로 적어도 되고, 정해진 항목만 먼저 채워도 됩니다.

    3

    이미지는 핵심 장면만 넣으세요

    메인 화면, 플레이 화면, UI는 선택 사항이에요. 아트 컨셉은 글로 톤과 키워드를 정리해 두면 발표에 도움이 됩니다.

    4

    오른쪽 문서를 확인하세요

    작성 내용은 A4 페이지에 자동으로 나뉘어요. 빈 항목은 문서에 나오지 않으며, 페이지 아래에서 전체 쪽수를 확인할 수 있어요.

    5

    필요한 파일로 저장하세요

    PDF는 제출·공유용, PPTX는 문구·선·이미지를 각각 수정할 수 있는 A4 슬라이드, Figma SVG는 추가 디자인 편집용으로 활용할 수 있어요.
